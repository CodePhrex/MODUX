# MODUX Visual Assets

The approved branding includes a cyan/purple hexagonal M icon, dark splash screen, dashboard, theme browser and theme creator mockups.

## Target folders
- `assets/brand/` — official logo, icon, palette and branding exports
- `assets/mockups/` — approved multi-screen concept artwork and individual screen mockups
- `assets/wallpapers/` — licensed demo wallpapers

## Provenance
The original approved concept artwork was generated in the project conversation. The GitHub text-file integration cannot upload the image bytes directly. This directory documents the asset placement plan; **the image files are not yet committed**.

Do not treat placeholder illustrations or screenshots as approved production assets.
